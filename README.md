# TechStore - Versao Inicial

Este repositorio contem a versao inicial do projeto **TechStore**, um site desenvolvido com **HTML, CSS e JavaScript puro**.

O projeto foi criado em grupo como Projeto Integrador da faculdade, servindo como a primeira base da aplicacao, com o objetivo de estruturar as telas, os fluxos principais e a identidade visual antes da migracao para uma versao mais completa em Angular.

A partir desta versao inicial, desenvolvemos uma nova implementacao utilizando **100% Angular**, mantida em outro repositorio.

> Link da versao em Angular: **[https://github.com/juniorsousa53339-svg/PI-ecommerce-informatica/tree/pi-Angular]**

## Sobre o projeto

A TechStore simula uma loja de tecnologia, com paginas para apresentacao, listagem de produtos, carrinho, login e gerenciamento de produtos.

Esta versao serviu como prototipo funcional e base visual para validar a navegacao, a organizacao das telas e as principais funcionalidades antes da reestruturacao em Angular.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript puro
- Font Awesome
- Boxicons

## Funcionalidades

- Pagina inicial da loja
- Listagem de produtos
- Busca e categorias de produtos
- Carrinho de compras
- Tela de login
- Controle simples de autenticacao
- Area de gerenciamento de produtos
- Cadastro, edicao e exclusao de produtos na interface

## Como executar

Por ser um projeto feito apenas com HTML, CSS e JavaScript puro, nao e necessario instalar dependencias.

1. Clone o repositorio:

```bash
git clone [https://github.com/Luife-correia/Projeto-PI.git]
```

2. Acesse a pasta do projeto:

```bash
cd Projeto-PI
```

3. Abra o arquivo `index.html` no navegador.
